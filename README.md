# Diabetes Trends in Azerbaijan (2000–2024)

This repository presents a **visual analytics–focused exploration** of diabetes prevalence in Azerbaijan using publicly available data from the **IDDA Open Data Portal**.  
The primary objective of this project is to **communicate trends, patterns, and structural shifts through data visualization**, rather than to build complex predictive models.

## Dataset
- **Source:** IDDA (Integrated Disease Data Analytics) Open Data Portal  
- **Dataset:** Population Incidence and Registration of Diabetes in Azerbaijan  
- **Coverage:** 2000–2024  

## Focus of the Analysis
The analysis is centered on **visual storytelling and exploratory data analysis**, including:

- Long-term trends in total registered diabetes cases  
- Comparison between new annual cases and cumulative prevalence  
- Composition analysis: Type 1 (insulin-dependent) vs. Type 2 (non–insulin-dependent) diabetes  
- Relative growth indices (base year 2000)  
- Registry inflow vs. estimated outflow (attrition proxy)  
- Context-aware visual annotations and trend-based projections  

## Files
- **Jupyter Notebook (.ipynb):** Interactive notebook containing all visualizations and insights  
- **HTML Export (.html):** Static, shareable version of the notebook with rendered charts  

## Tools & Libraries
Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly

## Notes
All projections and derived metrics are included to support **visual interpretation of trends** and should be considered baseline or exploratory rather than causal or epidemiological forecasts.
